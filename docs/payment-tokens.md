# Payment Tokens Guide

This document describes how payment tokens work on ElcareHub.

## Supported Tokens

- XLM (native)
- USDC
- USDT
- Other stabilized coins

## Token Configuration

Tokens are configured in the frontend metadata file.

## Token Verification

All tokens must be verified before display.

## Token Onboarding

See `docs/runbooks/token-onboarding.md` for the full onboarding procedure.
